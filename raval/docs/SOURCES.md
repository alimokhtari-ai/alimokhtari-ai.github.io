# منابع و منشأ داده

## منبع عددهای دمو

`data/prices.csv` دادهٔ نمونهٔ تسک است. این فایل منبع محاسبهٔ همین برنامه است و قیمت بازار، موجودی نمایشگاه یا نو و کارکرده بودن خودروها را تأیید نمی‌کند. هر خروجی باید ردیف و نسخهٔ این منبع را نگه دارد.

نرخ اسمی سالانهٔ پیش‌فرض ۲۳٪ و سیاست گرد کردن به تومان کامل، فرض‌ها و تصمیم‌های صریح این پیاده‌سازی‌اند. این نرخ از منبعی دربارهٔ شرایط فروش واقعی برداشت نشده است.

## منابع فنی رسمی

| منبع | کاربرد در پروژه |
| --- | --- |
| [Groq Structured Outputs](https://console.groq.com/docs/structured-outputs) | قرارداد JSON برای استخراج و انتخاب شناسهٔ عبارت؛ مدل `openai/gpt-oss-20b` در فهرست پشتیبانی حالت strict قرار دارد. |
| [Telegram Bot API](https://core.telegram.org/bots/api) | قرارداد long polling، شناسهٔ update، وضعیت webhook و ارسال متن. |
| [Google Sheets PMT](https://support.google.com/docs/answer/3093185?hl=en) | مبنای پرداخت دوره‌ای ثابت، هماهنگی واحد نرخ و دوره و پرداخت در پایان دوره. |

خواندن این مستندات به معنی اجرای اتصال زنده نیست. در این نسخه کلید واقعی ارائه نشده و هیچ اتصال زنده‌ای نباید فقط از روی وجود آداپتور نتیجه گرفته شود. قالب JSON معتبر نیز باید جداگانه با متن درخواست و منبع CSV کنترل شود.

## فایل workflow

`workflow.json` یک شرح JSON مستقل از ابزار برای همین پیاده‌سازی پایتون است. این فایل credential، شناسهٔ نود n8n یا ساختار export آن ابزار را ندارد و **قابل Import مستقیم در n8n نیست**.
