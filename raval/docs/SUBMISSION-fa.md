# بستهٔ ارسال روال

## فایل‌هایی که به بات می‌فرستی

۱. `RAVAL-VC005-Demo.mp4`: ویدیوی اجرای واقعی workflow محلی، با نمایش سؤال مبهم و تست حفظ قیمت.

۲. `RAVAL-VC005.zip`: پروژهٔ کامل Python، رابط فارسی، CSV نمونه، آداپترهای اختیاری، آزمون‌ها و راهنما.

۳. `RAVAL-VC005-Prompts.md`: پنج پرامپت کلیدیِ خلاصه‌شده و محل پرامپت‌های زمان اجرا.

۴. `RAVAL-workflow.json`: توصیف مسیر workflow پایتون؛ این فایل برای import در n8n نیست. کد قابل اجرا داخل ZIP است.

## معرفی کوتاه، آمادهٔ ارسال

«روال» رو ساختم؛ دستیار پیش‌فاکتور خودرو که درخواست مشتری رو می‌گیره، مدل و سال رو مشخص می‌کنه و قیمت و شرایط رو از CSV می‌خونه. اقساط با کد Python حساب می‌شن و کنار هر پاسخ، ردیف منبع و مسیر پردازش دیده می‌شه. اگر سال معلوم نباشه سؤال می‌پرسه؛ اگر خودرو توی جدول نباشه، از ردیف‌های واقعی گزینه پیشنهاد می‌ده. برای این تحویل، خواندن فایل و محاسبات واقعاً اجرا می‌شن؛ مدل در حالت نمونه است و پنل تلگرام شبیه‌سازه. کد اتصال Groq و بات تلگرام هم آماده است.

## توضیح فنیِ کوتاه برای قید ویژه

قیمت، درصد پیش‌پرداخت و تعداد اقساط وارد ورودی مدل نمی‌شوند. مدل در حالت اتصال فقط مشخصات درخواست و شناسهٔ عبارت‌های مجاز را برمی‌گرداند. متن مالی از ردیف اعتبارسنجی‌شدهٔ CSV و خروجی محاسبهٔ Decimal ساخته می‌شود. خود قیمت گرد نمی‌شود؛ سیاست گردکردن فقط برای مقدارهای محاسبه‌شده است و قسط آخر مانده را تسویه می‌کند.

## چیزی که باید روشن گفته شود

از جایگزین مجاز تسک استفاده شده: CSV به جای Google Sheets، کد Python برای workflow، و حالت نمونهٔ مدل به علت نبود کلید API. اتصال واقعی مدل و Telegram در ویدیو ادعا نشده است. در صورت فعال‌کردن اتصال‌ها، کلیدها فقط در محیط سیستم تنظیم می‌شوند و به فایل ZIP اضافه نمی‌شوند.

سه سؤال کوتاهِ فرم هنوز ارائه نشده‌اند؛ پاسخ نهایی هرکدام باید با متن خود همان سؤال تنظیم شود.
