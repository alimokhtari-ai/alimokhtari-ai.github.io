# Ali Mokhtari — Portfolio

Personal site for [Ali Mokhtari](https://github.com/alimokhtari-ai), built as a lightweight static website and deployed through GitHub Pages.

## Local preview

Open `index.html` in a modern browser. There is no build step or runtime dependency.

## Deployment

Every push to `main` deploys the site using the GitHub Pages workflow in `.github/workflows/deploy-pages.yml`.
