# دخل

دفتر دخل‌وخرج شخصی · ترک Vibe Coder · کد متقاضی **VC-005**

دخل کمک می‌کند برای هر ماه شمسی ببینید چقدر پول وارد شده، چقدر خرج شده، پول بیشتر کجا رفته و کدام دسته به سقف ماهانه‌اش نزدیک شده است.

## اجرا

1. فایل ZIP را از حالت فشرده خارج کنید.
2. فایل `index.html` را با دوبار کلیک در مرورگر باز کنید. برای بررسی نسخهٔ تحویلی، مرورگر دسکتاپ Chrome یا Edge پیشنهاد می‌شود.
3. از حالت خالی شروع کنید یا با انتخاب داده‌های نمونه، مسیر کار اپ را ببینید.

نصب، ثبت‌نام، سرور، اتصال به اینترنت و کلید API لازم نیست. فایل نهایی `index.html` شامل کد، استایل و فونت موردنیاز اپ است. پوشهٔ `src` نسخهٔ خوانای کدها را نگه می‌دارد.

## استفادهٔ روزمره

- **ثبت تراکنش:** نوع درآمد یا هزینه، مبلغ، دسته، تاریخ و توضیح را وارد کنید.
- **بررسی ماه:** ماه شمسی را انتخاب کنید تا جمع درآمد، هزینه، مانده و سهم دسته‌ها را ببینید.
- **اصلاح اطلاعات:** از بخش تراکنش‌ها، مورد ثبت‌شده را ویرایش یا حذف کنید. جست‌وجو و فیلترها پیدا کردن تراکنش را راحت‌تر می‌کنند.
- **دسته‌ها و سقف‌ها:** عنوان دسته و سقف هزینهٔ آن را تنظیم کنید. سقف‌ها برای بررسی هزینه‌های ماهانه به کار می‌روند.
- **سقف هر ماه:** سقف را برای ماه شمسی انتخابی تغییر دهید؛ سقف ماه‌های دیگر دست‌نخورده می‌ماند. دستهٔ دارای تراکنش به‌جای حذف سابقه، بایگانی می‌شود.
- **پشتیبان:** برای نگهداری یا انتقال داده‌ها، خروجی JSON بگیرید. بازیابی JSON با بررسی ساختار داده انجام می‌شود.
- **CSV:** برای کار با تراکنش‌ها در Excel، خروجی CSV بگیرید.

همهٔ مبلغ‌ها **تومان** هستند. ارقام نمایشی اپ فارسی‌اند. تاریخ تراکنش در داخل داده‌ها به شکل استاندارد میلادی نگهداری می‌شود و نمایش و دسته‌بندی ماهانهٔ اپ شمسی است. ظاهر تقویم انتخاب تاریخ به زبان و تنظیمات مرورگر بستگی دارد.

داده‌های نمونه آزمایشی‌اند و به حساب مالی واقعی تعلق ندارند. وجود نشان نمونه را هنگام ارائهٔ دمو حفظ کنید.

## قاعدهٔ دقیق هشدار

هشدار زمانی فعال می‌شود که مجموع هزینهٔ یک دسته در ماه انتخابی **بیشتر از ۸۰٪ سقف همان دسته** باشد. رسیدن دقیق به ۸۰٪ هنوز عبور از حد نیست.

برای سقف ماهانهٔ ۱٬۰۰۰٬۰۰۰ تومان:

| مجموع هزینه | نتیجه |
| --- | --- |
| ۸۰۰٬۰۰۰ تومان | هنوز هشدار عبور از ۸۰٪ ندارد |
| ۸۵۰٬۰۰۰ تومان | نزدیک سقف؛ هشدار فعال است |
| ۱٬۰۰۰٬۰۰۰ تومان | سقف کامل شده است |
| ۱٬۱۰۰٬۰۰۰ تومان | ۱۰۰٬۰۰۰ تومان بیشتر از سقف خرج شده است |

سقف صفر به معنای نداشتن سقف برای آن دسته است؛ درآمدها وارد محاسبهٔ مصرف سقف هزینه نمی‌شوند.

## فارسی و عدد در Excel

CSV با **UTF-8 BOM** ساخته می‌شود. عنوان ستون‌ها و متن‌ها فارسی‌اند و مبلغ در فایل به صورت عدد قابل محاسبه ذخیره می‌شود. ویرگول، علامت نقل‌قول و خط جدید در توضیحات، ساختار CSV را به هم نمی‌زنند. متن‌های کاربر که ممکن است به شکل فرمول تفسیر شوند نیز خنثی می‌شوند.

اگر Excel به دلیل تنظیمات منطقه‌ای، ستون‌ها یا حروف را درست تشخیص نداد، از مسیر **Data → From Text/CSV** فایل را وارد کنید؛ Encoding را **UTF-8** و جداکننده را **Comma** بگذارید. این راهنما به معنی انجام تست در خود نرم‌افزار Excel نیست.

## داده‌ها کجا می‌مانند؟

داده‌ها در `localStorage` همان مرورگر نگهداری می‌شوند. پاک کردن داده‌های مرورگر، استفاده از حالت ناشناس یا باز کردن فایل در مرورگر یا مسیر دیگری می‌تواند دسترسی به آن نسخهٔ داده‌ها را تغییر دهد. پیش از جابه‌جایی فایل یا پاک کردن مرورگر، خروجی JSON بگیرید.

این نسخه همگام‌سازی بین دستگاه‌ها یا حساب آنلاین ندارد. اطلاعات مالی توسط خود اپ به سروری ارسال نمی‌شود. بررسی مستقل در Safari و باز کردن خروجی در نسخه‌های مختلف Excel، فقط در صورت وجود گزارش آزمون مربوط باید تأییدشده تلقی شود.

## راهنمای بسته

- `index.html`: اجرای مستقیم اپ.
- `src/`: کدهای خوانا برای بررسی و توسعه.
- `tests/`: آزمون‌های منطق برنامه.
- `tests/evidence/`: نتیجهٔ واقعی آزمون‌ها و اطلاعات ضبط دمو.
- `examples/`: CSV و پشتیبان JSON آزمایشی که از خود اپ در ویدیوی دمو دانلود شده‌اند.
- `docs/QA-REVIEW.md`: گزارش مستقل مرورگر و حدود بررسی.
- `docs/KEY-PROMPTS-fa.md`: پنج پرامپت کلیدی ساخت و بازبینی.
- `docs/DEMO-SCRIPT-fa.md`: سناریوی ارائهٔ حدود دو دقیقه‌ای.
- `docs/EXPLAINER-fa.md`: سه توضیح کوتاه آماده دربارهٔ معماری، کار با AI و محدودیت‌ها.

## نتیجهٔ بررسی نسخهٔ تحویلی

۱۵ آزمون منطق مالی و تاریخ، ۱۸ سناریوی واقعی مرورگر و ۳ سناریوی مشخص حفظ داده در تغییر هم‌زمان دو تب، همگی موفق بودند. تست تقویم شامل ۱٬۱۵۰ رفت‌وبرگشت روزانهٔ میلادی و شمسی است. تست مرورگر از خود فایل HTML و بدون سرور اجرا شده؛ درخواست شبکه یا خطای JavaScript مشاهده نشده است.

سه نمای اصلی و فرم در عرض‌های ۳۶۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ بررسی شده‌اند. فونت واقعی Estedad نیز با بازرس مرورگر تأیید شده است. آزمون‌های فایل CSV، بایت‌ها و ساختار فایل را بررسی کرده‌اند؛ نرم‌افزار واقعی Excel، Safari و گوشی فیزیکی در این محیط آزموده نشده‌اند.

## برای بررسی کد

اجرای اپ به ابزار توسعه نیاز ندارد. برای بازسازی HTML از منابع، Python 3 کافی است:

```bash
python3 build.py
```

تست‌های منطق با Node.js و بدون نصب پکیج اجرا می‌شوند:

```bash
node tests/core.test.cjs
```

تست‌های مرورگر و ضبط به Playwright و مرورگر تست نیاز دارند؛ این‌ها وابستگی توسعه‌اند و داخل اجرای اپ استفاده نمی‌شوند.

نام فونت، نسخهٔ ۸.۵، منبع و هش فایل در `assets/font-manifest.json` ثبت شده‌اند. مجوز اصلی فونت همراه فایل مستقل HTML و پوشهٔ assets نگهداری شده است.
