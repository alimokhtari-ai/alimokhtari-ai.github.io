# توضیح‌های کوتاه برای ارائه

**پروژه: دخل · متقاضی: VC-005**

متن سه سؤال نهایی هنوز ارائه نشده؛ این‌ها توضیح‌های آماده‌اند، نه پاسخ به سؤال‌های ندیده. پس از مشخص شدن سؤال‌ها، متن متناسب با همان پرسش‌ها انتخاب و اصلاح شود.

## معماری و دلیل انتخاب آن

دخل با HTML، CSS و JavaScript ساخته شده و فایل نهایی بدون نصب و سرور باز می‌شود. منطق محاسبه و تاریخ از رابط جداست تا مستقل بررسی شود. مبلغ‌ها عدد صحیحِ تومان‌اند؛ تاریخ استاندارد ذخیره می‌شود و گزارش‌ها بر اساس ماه شمسی ساخته می‌شوند. داده‌ها در مرورگر می‌مانند و JSON برای پشتیبان و CSV برای کار با Excel در نظر گرفته شده است.

## نقش AI و نقطه‌های مهم بازبینی

کار را به قرارداد داده، منطق مالی، رابط فارسی و بررسی نهایی تقسیم کردم و برای هر بخش معیار پذیرش گذاشتم. تمرکز بازبینی روی جاهایی بود که ظاهر خوب خطا را پنهان می‌کند؛ مثل تفاوت رسیدن به ۸۰ درصد با عبور از آن، جابه‌جایی ماه شمسی، ورود مبلغ فارسی و خراب نشدن CSV با توضیح چندخطی. نتیجهٔ هر آزمون باید با خروجی واقعی همان اجرا سنجیده شود.

## محدودهٔ این نسخه و ادامهٔ منطقی

این نسخه برای دفتر مالی شخصی روی یک مرورگر ساخته شده است. نگهداری بلندمدت یا انتقال داده با پشتیبان JSON انجام می‌شود و همگام‌سازی بین دستگاه‌ها داخل این نسخه نیست. برای ادامه، اول بازیابی و قابلیت اطمینان داده را تقویت می‌کنم و بعد سراغ حساب کاربری و همگام‌سازی می‌روم. باز شدن در مرورگرهای دیگر یا نسخه‌های مختلف Excel را فقط بعد از آزمون همان محیط تأیید می‌کنم.
